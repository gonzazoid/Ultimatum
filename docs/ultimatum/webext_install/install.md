### How to install webextensions?

You can install them from [Chrome Web Store](https://chromewebstore.google.com/) or from [Opera add-ons](https://addons.opera.com/).

Below is the prosess of installing the Browsec extension from the Chrome Web Store.

Open Ultimatum. Select menu:

![](/docs/ultimatum/webext_install/webext_install_01_menu.jpg)

Tap on extensions option:

![](/docs/ultimatum/webext_install/webext_install_02_ext_list.jpg)

Tap on menu button (left top corner, before logo):

![](/docs/ultimatum/webext_install/webext_install_03_ext_menu.jpg)

Tap on link to Chrome web store, when site opens type the extension's name in search bar:

![](/docs/ultimatum/webext_install/webext_install_04_type_ext_name.jpg)

Tap on name and wait until page is loaded. You can choose "desktope site" in options or just turn your phone to the side to switch to landscape mode:

![](/docs/ultimatum/webext_install/webext_install_05_ext_page.jpg)

Tap on "Add to Chrome" button and wait until it becomes "Remove from Chrome" button:

![](/docs/ultimatum/webext_install/webext_install_06_ext_installed_page.jpg)

At this moment webextension has been successfully downloaded and installed. Let's check if it's true. Switch back to webextensions page:

![](/docs/ultimatum/webext_install/webext_install_07_back_to_ext_list.jpg)

You'll see the extension at the list:

![](/docs/ultimatum/webext_install/webext_install_08_ext_installed.jpg)

Tap on it's logo and accept the terms:

![](/docs/ultimatum/webext_install/webext_install_09_accept_the_terms.jpg)

Close popup and enjoy the extension:

![](/docs/ultimatum/webext_install/webext_install_10_close_popup.jpg)

![](/docs/ultimatum/webext_install/webext_install_11_ext_working.jpg)

That's pretty much it!
